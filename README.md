# QKCV Implementation Package

## Package Contents
This archive contains two standalone code repositories implementing QKCV-enhanced architectures:

1. **Lightweight Models**  
   Directory: `/static_feature_in_attention_layer`  
   - Implements QKCV-modified attention mechanisms for resource-efficient time series models  
   - Supported architectures: Transformer, Informer, PatchTST, TFT 

2. **Foundation Model Adaptation**  
   Directory: `/timesfm-master`  
   - TimeFM (Google Research) integration with QKCV  
   - Fine-tuning scripts

Detailed documentation is available in each repository's `README.md`.
